# LocalReach

**Connect local devices to approved applications without networking complexity.**

LocalReach is an early-stage open-source research and design project for secure, simple access to LAN-only hardware such as printers and attendance devices.

**Status:** architecture and UX research; no working connector or production service yet.

Our goal: *Install once. Click Connect. Your devices are ready.* An initial local component is still necessary when legacy hardware cannot connect outbound by itself.

The architecture, security model, delivery semantics, rollout and one-click experience are being specified in the `docs/` directory on the documentation branch before implementation. We welcome design feedback and research contributions.

See the documentation pull request for the complete proposed design. Do not deploy this as a network gateway; it has no implementation yet.
